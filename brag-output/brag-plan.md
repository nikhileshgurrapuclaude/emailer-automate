# Brag plan: Emailer Automation Studio (60s presentation reel)

**Source:** the "Emailer Automation Studio" deck/PDF plus the live app (emailer-automate.vercel.app), with screenshots captured from the real studio and hub.
**Format:** landscape 1920×1080, 30fps, 60s (the user asked for about a minute, so the brag default of about 20s doesn't apply).
**Tone:** `default`, leaning playful-agency in ting.in's style: bold lowercase headlines, Courier typewriter labels, yellow `#FFEE00` on near-black `#1A1A1A`, off-white `#FAF8F2`, and yellow/black hazard-stripe wipes.

## Rubric
- **What:** a self-serve studio that turns on-brand, Outlook-safe HTML emailers into a fill-in-the-template job.
- **Who:** finance and wealth comms teams (deal, marketing, brand) and the developers they currently queue on.
- **Edge:** brand workspaces carry the logo, signature and footer, templates are table-based for Outlook, and you get a live preview and one-click export.
- **Best claim:** "client-ready HTML emailers in minutes, not developer hours."
- **Visual hook:** emailer types typing onto black, then "every one lands on a developer’s desk."
- **Real UI:** the brand hub, the studio editor, sidebar, preview and Download ZIP button. The preview pane shows the `demo_emailer` template, which has placeholder copy only.
- **Privacy:** the live preview pane showed a real press release with named executives, so it's overlaid with the demo emailer. There are no people's names or personal data in the video.
- **Caption:** see share-copy.txt.

## Music
120 BPM in A minor (Am–F–C–G, one bar = 2s). Every scene cut lands on a bar or beat, and every SFX (clicks, typing, pops, whooshes) is placed on the same 1/16 grid.
